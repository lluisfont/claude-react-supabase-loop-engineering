# Changelog

## 1.0.0 - 2026-07-25

### Added

- Claude Code repository instructions and safe command permissions.
- Independent `spec-verifier` agent.
- Autonomous `test-fix-loop` implementation agent.
- Controlled PLAN, targeted test, INSPECT, correction and VERIFY workflow.
- React, TypeScript and Tailwind CSS review controls.
- Supabase migration, Auth, RLS, Storage, Realtime and Edge Function controls.
- Vitest, React Testing Library, MSW, Playwright, pgTAP, Deno Test, axe-core and Lighthouse CI mappings.
- Test actor and RLS readiness templates.
- Loop budgets, stagnation, oscillation, repeated-failure and scope-drift controls.
- Protection against remote destructive Supabase operations and service-role exposure.
